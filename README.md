# Sales-data-analysis
📌 Overview

This project explores Diwali Sales Data to uncover trends in customer purchasing behavior, demographics, and revenue patterns. The focus is on cleaning raw data, performing exploratory analysis, and creating clear visualizations to highlight actionable business insights.

🎯 Objectives

Understand customer demographics and buying behavior

Identify top-performing product categories and states

Highlight revenue drivers and high-value customer segments

🔑 Approach

Data Cleaning: Removed irrelevant columns, handled null values, corrected data types

Exploratory Analysis: Analyzed customer attributes (age, gender, occupation, marital status, state)

Visualization: Built plots using Matplotlib & Seaborn to explain sales trends and patterns

📊 Key Insights

Women contributed higher sales compared to men

Married women aged 26–35 years emerged as the top buyers

States like Uttar Pradesh, Maharashtra, and Karnataka led in revenue contribution

Customers from IT, Healthcare, and Aviation sectors had the highest purchasing power

🛠️ Tools & Libraries

Python (Pandas, NumPy)

Matplotlib & Seaborn (Data Visualization)

Jupyter Notebook

💡 Purpose

This project is intended to demonstrate data analysis skills including:
✔ Cleaning messy datasets
✔ Performing EDA
✔ Extracting business insights from data
✔ Communicating results visually
